# 特斯拉车主手册 · 辅助驾驶功能

辅助驾驶 是指一套可以让驾驶更方便、更轻松的高级辅助驾驶
功能。这些功能都无法实现 Model 3 自动驾驶或取代您的驾驶员
身份。
您有责任熟悉这些功能的各项限制，关注路面情况，随时准备立
即采取措施。有关更多限制、注意事项和警告，请参阅辅助驾驶 
限制和警告 页码 103。
主动巡航控制
所有特斯拉车辆均配备主动巡航控制。主动巡航控制 可保持车
速以及与前方车辆（若有）之间的可调节跟车距离。有关详细信
息，请参阅主动巡航控制 页码 89。
注： 根据市场区域、生产日期、车辆配置、购买的选装件、辅
助驾驶硬件和软件版本，您的车辆可能未配备特斯拉辅助驾驶，
或者相关功能的表现与说明有所不同。
其他辅助驾驶功能
此外，您的车辆可能还配备以下辅助驾驶功能。根据市场区域、
生产日期、软件版本、辅助驾驶硬件和车辆配置，启用的特定功
能可能有所不同。如需了解车辆定制信息，请点击应用程序启动
器，然后选择“手册”应用程序，在车辆触摸屏上查看《车主手
册》。
• 辅助转向：保持车速以及与前方车辆之间的距离，同时将 
Model 3 保持在车道内（请参阅辅助转向 页码 92）。除辅
助转向之外，您的车辆可能还配备有辅助变道（辅助变道 页
码 93）和辅助导航驾驶（请参阅辅助导航驾驶 页码 
93）。
• 辅助泊车：将 Model 3 平行或垂直停车（请参阅辅助泊车 页
码 98）。
• 召唤功能：允许您从车外使用 Tesla 手机应用程序对 Model 3
执行驻车和找回操作（请参阅召唤功能 页码 100）。
工作原理
辅助驾驶 功能使用Model 3 上的摄像头。Model 3 的前后左右
都装有摄像头（请参阅摄像头 页码 18）。
Model 3 配备一个安装在后视镜的驾驶室摄像头，用于监控驾驶
员是否注意力集中。您有责任注意路况，随时做好立即采取行动
的准备。
当或辅助转向启用时，Model 3 会显示一系列逐步升级的警告，
提醒您履行自己的职责。
如果没有响应，辅助驾驶将停用，不再适用于剩余驾驶时间。
警告： 辅助驾驶 功能并不保证能够发出碰撞预警或避免
碰撞。驾驶员有责任时刻保持警惕，安全驾驶，并掌控车
辆。切勿依靠辅助驾驶来充分降低 Model 3 车速。务必观
察前方路况并准备随时采取纠正措施。否则可导致严重伤
害或死亡。
警告： 某些情况下可能需要驾驶员干预驾驶。有关可能需
要驾驶员干预的场景的示例，请参阅辅助驾驶 限制和警告 
页码 103。当遇到机动车、非机动车和行人时，可能无需
驾驶员进行干预。
您有责任熟悉辅助驾驶的各项限制，并随时做好干预驾驶的准
备。有关更多限制、注意事项和警告，请参阅辅助驾驶 限制和
警告 页码 103。
关于 辅助驾驶

主动巡航控制 保持车速以及与前方车辆（若有）之间的可调节
跟车距离。
使用须知： 主动巡航控制
在使用主动巡航控制之前，请点击控制 > 辅助驾驶以自定义其工
作方式。
• 设定速度：选择是以当前探测到的限速还是以当前行驶速度
启用主动巡航控制。点击 控制 > 辅助驾驶 并选择速度限制或
当前速度。
• 偏移：如果选择速度限制，您可以点击设定速度偏离值来指
定偏离值。您可以选择固定（按照适用于所有道路的特定数
量调整巡航速度），也可以选择百分比（按照探测到的道路
限速的百分比调整巡航速度）。
• 辅助驾驶激活（如果配备）：选择如何激活辅助驾驶。如果
设置为单击，则按一下右滚轮按钮可同时启用主动巡航控制
和辅助转向。如果设置为双击，则必须按两下右滚轮按钮才
能启用辅助转向。
注： 根据饰板、配置和生产日期，您的车辆可能未配备辅助
驾驶激活设置。
注： 辅助驾驶激活 必须设置为双击才能在不启用辅助转向的
情况下单独启用主动巡航控制。
• 绿色交通信号灯蜂鸣：如果开启，等候中的红色交通信号灯
变绿时，本车便会发出蜂鸣声。如果您目前未使用主动巡航
控制或辅助转向，并且在您等红灯时前方还有一辆车，当前
方车辆前进时，您的车辆会发出蜂鸣声。
使用 主动巡航控制
要启用主动巡航控制，请点击控制 > 辅助驾驶 > 主动巡航控制。
或者，选择辅助转向并确保辅助驾驶激活（若配备）设置为双
击。
主动巡航控制 在车速介于 30 km/h 和 150 km/h 之间时可用。
如果检测到 Model 3 前方至少 1.5 米处有车辆，则可以在车速较
低的情况下启用主动巡航控制。
注： 主动巡航控制 在辅助转向启用且辅助驾驶激活（若配备）
设置为单击后无法使用。
要使用主动巡航控制：
1. 按下右滚轮按钮，然后松开加速踏板，使主动巡航控制能够
保持巡航速度。发出蜂鸣音，表示主动巡航控制现已启用。
2. 要更改设定速度，可向上滚动右滚轮（提高速度）或向下滚
动右滚轮（降低速度）。您可以随时踩下加速踏板以暂时忽
略设定的巡航速度。
3. 要取消主动巡航控制，请按下右滚轮按钮或踩下制动踏板。
如果主动巡航控制可用但未启用，触摸屏会以灰
色显示巡航速度。显示的数字表示在启用主动巡
航控制后会设置的速度。
当主动巡航控制以设定速度进行主动巡航时，速
度会以蓝色字样突出显示。
警告： 主动巡航控制 为实现驾驶舒适性和便利性而设
计，不属于碰撞警告或规避系统。驾驶员有责任时刻保持
警惕，安全驾驶，并掌控车辆。切勿依靠主动巡航控制来
充分降低 Model 3 车速。务必观察前方路况并准备随时采
取纠正措施。否则可导致严重伤害或死亡。有关详细信
息，请参阅辅助驾驶 限制和警告 页码 103。
使用 主动巡航控制
当主动巡航控制处于激活状态并且保持设定速度时，速度将在触
摸屏上以蓝色字样突出显示。
保持设定速度
主动巡航控制处于活动状态时，只要未探测到前方有车辆，
Model 3 就会保持设定的巡航速度。当跟在某辆车后巡航时，
Model 3 会根据需要提高或降低车速，以在设定速度之下保持选
择的跟车距离。
随时可以踩下加速踏板进行加速，但当松开踏板时，Model 3 将
继续以设定速度巡航。
Model 3 在驶入和驶出弯道时也会调整巡航速度。
当 Model 3 主动减速以便与前车保持选定距离时，制动灯亮起。
您可能会发现制动踏板有轻微移动。但是，当 Model 3 加速时，
加速踏板不会移动。
更改设定速度
向上滚动右滚轮可提高设定速度，向下滚动则可降低设定速度。
要将巡航速度更改为当前限速（包括您指定的任何偏移），请按
下触摸屏上的速度限制标志。
Model 3 可能需要几秒钟时间才能达到新的巡航速度。
主动巡航控制

调整跟车距离
要调整希望 Model 3 与前方车辆保持的跟车距离，请向左或向右
按方向盘的右滚轮按钮。
最小跟车距离等级设置为 2。
注： 方向盘的设计可能有所不同，但功能相同。
每种设置对应一个基于时间的距离，表示 Model 3 从当前位置到
达前车后保险杠位置所需的时间。 主动巡航控制 会保留您的设
置，直至您再次对其进行更改。
随着跟车距离的调整，触摸屏将显示当前设置。
停车和减速
如果您的车速明显高于相邻车道的车辆，Model 3 会自动降低行
驶速度。该功能尤其适用于拥堵路段，或车辆需要不断变换车道
的情况。如果 Model 3 探测到其他车辆的行驶速度明显较慢，触
摸屏 将用箭头标示临近车道，并以灰色突出显示探测到的车
辆，Model 3 将适当减慢行驶速度。要暂时忽略此功能，请踩下
加速踏板。
跟车时，主动巡航控制在低速行驶时保持可用，即使 Model 3 完
全停下来也是如此。例如，即使 Model 3 在高速公路上车流量
大、交通拥堵的状况下减速至完全或接近完全停下来，主动巡航
控制将保持可用。当车流移动速度开始加快时，主动巡航控制会
再次加速至设定速度。
有时，当 Model 3 完全停下来时，主动巡航控制将进入“保持”
状态。如果出现这种情况，短踩加速踏板可恢复巡航。
当“保持”状态激活时，触摸屏 会显示“保持”
图标和一则表示需要继续进行巡航控制的消息。
Model 3 如果主动巡航控制在以下情况下激活，则会进入“保
持”状态：
• Model 3 停驶时间达到 5 分钟。
• Model 3 探测到附近有行人（不再探测到行人时，“保持”
状态会解除）。
• Model 3 突然看不到前方车辆。
• 探测到 Model 3 前方有障碍物。
在出口或附近巡航
在通行受控道路的出口附近巡航以及向匝道出口打转向信号灯
时，主动巡航控制认为您要驶离并开始降低 Model 3 的速度。如
果您没有驶上匝道出口，主动巡航控制将继续以设定速度巡航。
在右侧行驶地区，只有在最右侧车道行驶且在距离出口 50 米以
内打开右转向信号灯时，才会出现这种情况。在左侧行驶地区，
在最左侧车道上行驶且在距离出口 50 米内打开左转向信号灯
时，会出现这种情况。
巡航到通行受控道路的匝道入口上时，主动巡航控制会自动调整
设定的巡航速度，使其等于高速路段限速加指定的任何偏离值。
主动巡航控制

超车加速
短暂地开启转向信号灯，使 Model 3 加速超车。短暂地按住转向
信号灯，可以在不踩加速踏板的情况下迅速加速到设定速度，但
前提是：
• 主动巡航控制 正在运行且检测到前方有车辆。
• 检测到目标车道内无障碍物或车辆。
• Model 3 以低于设定速度但高于 72 km/h 的速度行驶。
Model 3 如果变道时间过长或 Model 3 离前方车辆太近，当达到
设定的巡航速度时停止加速。 Model 3 关闭转向信号灯时也会停
止加速。
取消操作 主动巡航控制
主动巡航控制 在以下情况时会取消：
• 按下 方向盘 上的右滚轮按钮。
• 踩下制动踏板。
• 您已超出150 km/h。
• 换入倒挡、驻车挡或空挡。
• 打开车门。
• 发生自动紧急制动事件（请参阅防撞辅助 页码 108）。
• 驾驶员的座椅安全带松开，和/或驾驶员离开座位。
• 超出主动巡航控制的功能边界。
主动巡航控制取消时，触摸屏上的巡航速度图标将变成灰色，表
示主动巡航控制不再有效。
主动巡航控制取消时，Model 3 不会滑行。相反，能量回收制动
会使 Model 3 减速，减速方式与无主动巡航控制时把脚从加速踏
板上移开来降低车速相同（请参阅能量回收制动 页码 71）。
主动巡航控制

本主题介绍如何启用和使用以下辅助驾驶功能。
注： 根据市场区域、生产日期、车辆配置、购买的选装件、辅
助驾驶辅助驾驶硬件和软件版本，您的车辆可能未配备以下功
能，或者相关功能的表现与说明有所不同。
• 辅助转向：与主动巡航控制相同，辅助转向将维持设定速度
（如果前方没有车辆）或设定的跟车距离（如果前方有车
辆）。此外，辅助转向会探测车道线、道路边缘，以及是否
存在车辆和物体，以便将 Model 3 保持在其行驶车道内（请
参阅辅助转向 页码 92）。
• 辅助变道：如果您在辅助转向处于激活状态时启用转向信号
灯，辅助变道将按转向信号灯指示的方向将 Model 3 驶入相
邻车道（请参阅辅助变道 页码 93）。辅助换道功能支持的
车速范围 5 km/h - 140 km/h。
• 辅助导航驾驶： 辅助导航驾驶 基于主动巡航控制和辅助转向
功能构建。当辅助转向处于激活状态时，辅助导航驾驶 允许
Model 3 提供建议，并且会自动变道（如果配置此功能）来
超过其他车辆并按导航路线行驶（请参阅辅助导航驾驶 页码 
93）。
这些功能使用 Model 3 上的摄像头提供的信息探测车道线、道路
边缘以及 Model 3 周围的其他车辆和道路使用者。
警告： 每次驾驶前和使用本主题所述的功能之前，确保所
有摄像头清洁，无障碍物阻挡（请参阅清洁摄像头 页码 
159）。摄像头和传感器（若配备）脏污，以及下雨和车
道线褪色等环境条件可能会影响性能。如果摄像头被遮挡
或遮蔽，Model 3 会在 触摸屏 上显示一则消息，辅助驾驶
功能可能无法使用。 
警告： 您有责任熟悉辅助转向的各项限制，以及可能需要
驾驶员干预的情况。有关详细信息，请参阅辅助驾驶 限制
和警告 页码 103。

辅助转向
注： 根据市场区域、生产日期、车辆配置、购买的选装件、辅
助驾驶硬件和软件版本，您的车辆可能未配备辅助转向，或者此
功能的表现与说明有所不同。
要启用辅助转向：
1. 点击控制 > 辅助驾驶 > 辅助转向。
2. 仔细阅读并理解弹出窗口中的内容，然后点击是。
辅助转向 在行驶速度介于 0 km/h 到 140 km/h 之间时可使用保
持车道。驾驶员启动的 辅助变道 在速度介于 5 km/h 到 140
km/h 之间时可用。
注： 要启用辅助转向，大灯必须设置为开或自动。尽管白天和
低光照条件下（黄昏或黑暗）都可以使用 辅助转向，但如果将
大灯设置为关，此功能会停止运行或无法使用。辅助转向启用
后，自适应大灯（某些车辆配备的是自动远光灯）会自动启用
（请参阅远光大灯 页码 67），雨刮器设置为自动。
要使用辅助转向：
1. 按下右滚轮按钮。
注： 如果辅助驾驶激活（若配备）的设置设为双击，则必须
按两下右滚轮按钮才能启用辅助转向（请参阅辅助转向 使用
须知 页码 92）。
2. 要更改设定速度，可向上滚动右滚轮（提高速度）或向下滚
动右滚轮（降低速度）。有关详细信息，请参阅使用 辅助转
向 页码 95。
3. 要取消辅助转向，请按下右滚轮按钮或踩下制动踏板。有关
详细信息，请参阅取消操作 辅助转向 页码 94。
启用辅助转向后，Model 3 会发出一声蜂鸣声来确认激活，并会
在触摸屏上简要显示一则消息，提示注意路况，并准备随时干预
驾驶。
为了指示辅助转向可用（但并未主动操控 Model 
3），触摸屏顶角会在行驶挡旁边显示一个灰色方
向盘图标。
辅助转向

当辅助转向启用且在主动控制Model 3 时，方向
盘图标为蓝色。
辅助转向能够探测到车道线时，它会在触摸屏上以蓝色显示行车
道的边缘。
每当辅助转向处于激活状态，主动巡航控制也处于激活状态。
如果出现辅助转向已启用却探测不到限速的情况，辅助转向会降
低行驶车速并将设定巡航速度限制在 70 km/h。尽管您可以手动
加速来超过限制速度，但只要踩下加速踏板，Model 3 就不会因
检测到障碍物而制动。 辅助转向 在您松开加速踏板后会降至限
速。驶离道路或使用方向盘禁用辅助转向后，可以根据需要再次
提升设定速度。
警告： 辅助转向 是一种需要动手操作的辅助功能。请始
终将双手放在方向盘上，留意道路及周围交通情况，并随
时准备采取应急措施。不遵守这些说明可能导致财产损
坏、严重的人员伤害或死亡。您有责任熟悉 辅助转向的各
项限制，以及此功能可能不会按预期工作的情况。有关详
细信息，请参阅辅助驾驶 限制和警告 页码 103。
辅助变道
注： 根据市场区域、生产日期、车辆配置、购买的选装件、辅
助驾驶硬件和软件版本，您的车辆可能未配备辅助变道，或者此
功能的表现与说明有所不同。
如果在辅助转向处于激活状态时开启转向信号灯，且以下条件得
到满足，Model 3 将按转向信号灯指示的方向驶入相邻车道：
• 转向指示灯已启用。
• 车道线指示允许变道。
• 变道过程中，Model 3 必须能够探测到目标车道的外侧车道
线。如果未检测到此车道线，变道将中止且 Model 3 将回到
原行车道。
• 摄像头的视野未被阻挡。
• Model 3 未探测到盲区内有车辆，或者目标车道的中间位置
有车辆或障碍物。如果检测到目标车道中有车辆或其他障碍
物，该物体将以红色显示在 触摸屏 的视觉画面中，在可以安
全变道之前 Model 3 不会完成变道。
警告： 尽管辅助变道用于探测相邻车道上的车辆和障碍
物，但您有责任始终进行目视检查，确保驶入目标车道安
全、恰当且符合当地交通规则。如果辅助变道由于数据不
足而无法变道，触摸屏将显示一系列警告。因此，在使用
辅助变道时，务必注意触摸屏并准备好手动操控Model 
3。
辅助变道进行变道的最低速度可能会因地区、相邻车道速度等因
素而异。请随时准备在需要时手动操控转向并变换车道。在自动
变道过程中，超车加速将激活，从而使 Model 3 能够加速到更接
近前方车辆的速度（请参阅超车加速 页码 96）。
开启转向信号灯时，辅助变道一次操控Model 3 变更一条车道。
再次变换车道需要在完成第一次变道后，再次启用转弯指示灯。
在 Model 3 变道时，务必留意前方行驶路线及周围区域，观察变
道性能。随时准备干预对车辆的操控。跨入相邻车道时，触摸屏 
会显示 Model 3 正在驶入的车道位置。
辅助导航驾驶
注： 根据市场区域、生产日期、车辆配置、购买的选装件、辅
助驾驶硬件和软件版本，您的车辆可能未配备辅助导航驾驶，或
者此功能的表现与说明有所不同。
要启用辅助导航驾驶，请点击控制 > 辅助驾驶 > 辅助导航驾驶。
接下来，如欲自定义辅助导航驾驶的工作方式，请点击自定义辅
助导航驾驶：
• 启动车辆即启用：选择是否为每条导航路线自动启用辅助导
航驾驶。启用后，每次行程开始时，路线指引列表中的辅助
导航驾驶按钮将处于已启用状态。
• 根据速度变道： 辅助导航驾驶 设计用于执行根据路线和速度
的变道操作。根据速度变道为可选功能。可利用这项设置禁
用“根据速度变道”，或指定辅助导航驾驶执行变道的迅捷
程度，以达到设定的巡航速度（柔和、普通或疾驰）。
• 驶出超车道：当导航到某一目的地时，选择是否希望辅助导
航驾驶操控车辆驶出超车道。除了根据路线和速度进行的变
道之外，辅助导航驾驶还会发出变道驶出超车道的请求，提
醒您在不超车时行驶在慢速车道上。选择否禁用此功能，并
保持 Model 3 在超车道上行驶，需要按照导航路线行驶的情
况除外。
• 要求变道确认：（如果配备）默认情况下，辅助导航驾驶需
要获得您的确认才会实施变道（亮起相应转向信号灯）。倘
若未在 3 秒钟内确认变道，则会响起蜂鸣声，提示辅助导航
驾驶需要您确认变道操作。
• 变道提醒：可指定是否接收变道通知以及具体接收方式
（关、蜂鸣、振动或同时）。
如果启动车辆即启用开启，辅助导航驾驶在以下情况时将自动启
用：
• 辅助转向 处于激活状态。
• 您正导航到目的地。
• 您位于通行受控的高速公路上。
启用后，每当激活导航路线并且路线至少包含一处通行受控道路
时，地图的路线指引列表上就会显示辅助导航驾驶按钮。
辅助转向

如果启动车辆即启用关闭，请点击路线指引上方的辅助导航驾驶
按钮启用此功能。选择辅助导航驾驶后，只要启用辅助转向就会
启用此功能。
导航到目的地时，辅助导航驾驶图标会显示在路
线指引列表中，此时，辅助导航驾驶可用但未激
活。
如果辅助导航驾驶处于激活状态，则图标为蓝
色。如果启动车辆即启用开启，只要开始导航，
辅助导航驾驶图标就会被选中。点击该图标以取
消辅助导航驾驶并恢复至辅助转向。
只要辅助导航驾驶处于活动状态，辅助导航驾驶按钮就以蓝色显
示，并且触摸屏会将Model 3 前方的行车道显示为一条蓝色线
条。
路线指引会在辅助导航驾驶要执行的操作（例如驶离匝道）旁边
显示辅助转向图标。
在辅助导航驾驶启用的情况下，Model 3 会根据速度和路线进行
变道。
• 根据速度变道： 辅助导航驾驶 变道以减少到达目的地的行驶
时间。例如，如果Model 3 前方车辆的行驶速度低于设定的
巡航速度，辅助导航驾驶将进入超车道超车。根据速度变道
为可选功能。
• 根据路线变道： 辅助导航驾驶 变道以规划前往目的地的路
线。例如，在Model 3 接近导航路线指定的匝道出口时，辅
助导航驾驶会进入出口车道。
如果忽略基于路线的变道建议（例如，在快要到公路右侧匝道出
口时正行驶在左车道），辅助导航驾驶便无法操控车辆驶入匝道
出口，而是重新规划前往目的地的路线。
警告： 辅助导航驾驶 有时可能不会驶出匝道出口或变
道，即便该出口由导航路线所决定。请保持警觉，随时准
备手动转入匝道出口或变换车道，以便进入或驶离匝道出
口或交叉口。
辅助导航驾驶 根据所行驶道路的类型激活和停用。激活辅助导
航驾驶后，当靠近导航路线中的一处匝道出口或交叉口时，相应
的转向信号灯会亮起，辅助转向会将 Model 3 驶入匝道出口或交
叉口。
当您驶离通行受控的高速公路时，辅助导航驾驶将恢复至辅助转
向。届时，会发出蜂鸣声，并且触摸屏会将行进车道显示为蓝色
（不再只是Model 3 前方的一条蓝色线条）。辅助导航驾驶停用
时，辅助转向始终处于活动状态。务必做好采取适当措施的准
备。
注： 辅助导航驾驶 是一种需要驾驶员动手操作的辅助驾驶功
能。请始终将双手放在方向盘上，留意道路及周围交通情况，并
随时准备采取应急措施。不遵守这些说明可能导致财产损坏、严
重的人员伤害或死亡。您有责任熟悉 辅助导航驾驶的各项限
制，以及此功能可能不会按预期工作的情况。有关详细信息，请
参阅辅助驾驶 限制和警告 页码 103。
取消操作 辅助转向
辅助转向 在以下情况时会取消：
• 按下 方向盘 上的右滚轮按钮。
• 踩下制动踏板。
• 换入倒挡、驻车挡或空挡。
• 打开车门。
• 发生自动紧急制动事件（请参阅防撞辅助 页码 108）。
• 驾驶员的座椅安全带松开，和/或驾驶员离开座位。
• 您干预转向。
警告： 如果辅助驾驶激活（若配备）设置为双击，并
且辅助转向因为您开始手动操作方向盘而取消，主动
巡航控制将保持激活状态。如果辅助驾驶激活设置为
单击，并且辅助转向因为您开始手动操作方向盘而取
消，主动巡航控制也会取消。
• 您未响应建议您双手握住方向盘的持续声音警报和触摸屏上
显示的消息。
• 超出辅助转向的功能边界。
当辅助转向取消时，会发出蜂鸣声，辅助转向图标变为灰色，表
示辅助转向不再处于激活状态，消失则表示目前无法使用。
辅助导航驾驶 会在辅助转向取消时取消，如上所述。此外，辅
助导航驾驶会在出现以下情况时取消：
• 点击地图路线指引列表上的辅助导航驾驶按钮。在这种情况
下，辅助转向仍处于活动状态。
• 您离开通行受控的高速公路。这种情况发生时，辅助转向仍
处于活动状态。
当辅助导航驾驶取消但辅助转向仍处于活动状态时，会发出蜂鸣
音，显示从行车道上的一条蓝色线条变为车道两侧的两条蓝色线
条。
辅助转向取消时，Model 3 不会滑行。相反，能量回收制动会使 
Model 3 减速，减速方式与把脚从加速踏板上移开来降低车速相
同（请参阅能量回收制动 页码 71）。
辅助转向

使用 辅助转向
当辅助转向处于激活状态并且保持设定速度时，速度将在触摸屏
上以蓝色字样突出显示。
当辅助转向处于激活状态时，方向盘图标为蓝色，车道线将在视
觉画面上以蓝色突出显示。如果辅助导航驾驶也处于激活状态，
辅助导航驾驶按钮将以蓝色显示，并且触摸屏会将 Model 3 前方
的行车道显示为一条蓝色线条。
如果无法探测到车道线，辅助转向可根据前方车辆确定行车道。
大多数情况下，辅助转向会尝试使 Model 3 保持在行驶车道的中
间。但有时，辅助转向 可能会沿着与车道中部偏离的行驶路线
行驶（例如在探测到护栏的情况下）。
保持设定速度
辅助转向处于活动状态时，只要未探测到前方有车辆，Model 3
就会保持设定的巡航速度。当跟在车辆后面巡航时，Model 3 会
根据需要加速和减速，以在设定速度之下保持选择的跟车距离
（请参阅调整跟车距离 页码 95）。
随时可以踩下加速踏板进行手动加速，但当松开踏板时，Model 
3 将继续以设定速度巡航。
Model 3 在驶入和驶出弯道时也会调整巡航速度。
当 Model 3 主动减速以便与前车保持选定距离时，制动灯亮起。
您可能会发现制动踏板有轻微移动。但是，当 Model 3 加速时，
加速踏板不会移动。
更改设定速度
向上滚动右滚轮可提高设定速度，向下滚动则可降低设定速度。
要将巡航速度更改为当前限速（包括您指定的任何偏移），请按
下触摸屏上的速度限制标志。
Model 3 可能需要几秒钟时间才能达到新的巡航速度。
注： 在住宅区道路、没有中央隔离带的道路或通行不受控的道
路上，允许的最大巡航速度是受限的，并且触摸屏上会显示一条
消息。受限速度为道路速度限制加 10 km/h。
调整跟车距离
要调整希望 Model 3 与前方车辆保持的跟车距离，请向左或向右
按方向盘的右滚轮按钮。
最小跟车距离等级设置为 2。
注： 方向盘的设计可能有所不同，但功能相同。
每种设置对应一个基于时间的距离，表示 Model 3 从当前位置到
达前车后保险杠位置所需的时间。 辅助转向 会保留您的设置，
直至您再次对其进行更改。
随着跟车距离的调整，触摸屏将显示当前设置。
停车和减速
如果您的车速明显高于相邻车道的车辆，Model 3 会自动降低行
驶速度。该功能尤其适用于拥堵路段，或车辆需要不断变换车道
的情况。如果 Model 3 探测到其他车辆的行驶速度明显较慢，触
摸屏 将用箭头标示临近车道，并以灰色突出显示探测到的车
辆，Model 3 将适当减慢行驶速度。要暂时忽略此功能，请踩下
加速踏板。
辅助转向

跟车时，辅助转向在低速行驶时保持可用，即使 Model 3 完全停
下来也是如此。例如，即使 Model 3 在高速公路上车流量大、交
通拥堵的状况下减速至完全或接近完全停下来，辅助转向将保持
可用。当车流移动速度开始加快时，辅助转向会再次加速至设定
速度。
有时，当 Model 3 完全停下来时，辅助转向将进入“保持”状
态。如果出现这种情况，短踩加速踏板可恢复巡航。
当“保持”状态激活时，触摸屏 会显示“保持”
图标和一则表示需要继续进行巡航控制的消息。
Model 3 如果辅助转向在以下情况下激活，则会进入“保持”状
态：
• Model 3 停驶时间达到 5 分钟。
• Model 3 探测到附近有行人（不再探测到行人时，“保持”
状态会解除）。
• Model 3 突然看不到前方车辆。
• 探测到 Model 3 前方有障碍物。
在出口或附近巡航
在通行受控道路的出口附近巡航以及向匝道出口打转向信号灯
时，辅助转向认为您要驶离并开始降低 Model 3 的速度。如果您
没有驶上匝道出口，辅助转向将继续以设定速度巡航。
在右侧行驶地区，只有在最右侧车道行驶且在距离出口 50 米以
内打开右转向信号灯时，才会出现这种情况。在左侧行驶地区，
在最左侧车道上行驶且在距离出口 50 米内打开左转向信号灯
时，会出现这种情况。
注： 如果辅助导航驾驶处于活动状态，Model 3 将根据路线变道
以进入出口车道，并根据需要驶出匝道，以按照导航路线行驶。
巡航到通行受控道路的匝道入口上时，辅助转向会自动调整设定
的巡航速度，使其等于高速路段限速加指定的任何偏离值。如果
已启用辅助导航驾驶，此功能将在驶离通行受控道路时禁用（请
参阅取消操作 辅助转向 页码 94）。在这种情况下，辅助转向仍
处于活动状态。
超车加速
短暂地开启转向信号灯，使 Model 3 加速超车。短暂地按住转向
信号灯，可以在不踩加速踏板的情况下迅速加速到设定速度，但
前提是：
• 主动巡航控制 正在运行且检测到前方有车辆。
• 检测到目标车道内无障碍物或车辆。
• Model 3 以低于设定速度但高于 72 km/h 的速度行驶。
注： 如果辅助转向处于活动状态并且完全开启转向信号灯，

主动巡航控制
在使用主动巡航控制时，驾驶员有责任时刻保持警觉，安全驾
驶，并掌控车辆。行驶时务必观察路况，并准备根据需要采取正
确措施。
此外，驾驶员有责任根据道路状况和适用的速度限制，以安全的
速度巡航并保持安全的跟车距离。当主动巡航控制处于活动状态
时，请注意以下限制。
• 可能会存在巡航速度不随速度限制的变化而改变的情况。
• 主动巡航控制 无法根据路况和驾驶条件调整行驶速度。在有
急弯的曲折道路上、结冰或湿滑路面上或天气条件（如大
雨、大雪、浓雾等天气）不宜匀速行驶时，请勿使用主动巡
航控制。
• 切勿依赖主动巡航控制来保持准确或适合的跟车距离。
• 主动巡航控制 可能由于制动能力有限和处于上坡而无法提供
足够的速度控制。还可能会误判与前车之间距离。下坡时会
增加行驶速度，从而导致 Model 3 超过设定速度（也可能是
道路限速）。
• 主动巡航控制 偶尔会在不需要制动时或您未打算制动时发生
Model 3 制动。这可能是因为与前车距离过近、检测到相邻
车道（特别是在弯道上）有车辆或物体等。
• 由于车载全球定位系统的固有限制，可能会出现 Model 3 降
低车速的情况，特别是在出口或匝道出口附近探测到弯道
时，和/或启动目的地导航时未遵行指定路线时。
• 在某些情况下（如数据不足），主动巡航控制可能不会在公
路交叉道口或匝道出口处降低设定速度。
• 主动巡航控制 可能无法探测到所有物体（包括非机动车、行
人以及动物、锥桶、纸箱、水马、轮胎和三角警示牌等），
尤其在巡航速度高于 80 km/h 的情况下，如果车辆或物体仅
部分处于行驶车道，或前车驶出您所在的车道后，车辆前方
出现一个静止或移动缓慢的车辆或物体，则可能不会实施制
动/减速。
• 主动巡航控制 可能会对不存在或不在所行驶车道上的车辆或
物体做出反应，造成 Model 3 不必要或不正确地减速。
警告： 主动巡航控制在以下情况下尤其可能无法正常工
作：
• 道路有急转弯或显著高度变化。
• 道路标志和信号不清晰、模糊不清或维护不善。
• 能见度差（因大雨、大雪、浓雾等或夜间道路照明较
差造成）
• 您在隧道中或高速公路隔离带旁行驶，这会妨碍摄像
头视野
• 强光（比如迎面而来的大灯灯光或直射的阳光）妨碍
摄像头视野。
警告： 上述举例未尽述可能干扰主动巡航控制正常工作的
全部情形。 主动巡航控制 可能会因未知原因随时意外取
消。务必观察前方路况并准备采取适当的措施。驾驶员有
责任始终控制 Model 3。

不属于碰撞警告或规避系统。切勿依靠主动巡航控制来充
分降低 Model 3 车速。务必观察前方路况并准备随时采取

警告： 尽管主动巡航控制可以检测行人和自行车，但切勿

辅助转向
辅助驾驶 可以在以下情况时激活：中小雨天气（降雨量低于 25
mm/h）、大雾天气（能见度高于 150 米），以及弯道曲率半径
大于或等于 50 米的情况。
警告： 辅助转向 是一种需要驾驶员动手操作的辅助驾驶
功能。请始终将双手放在方向盘上，留意道路及周围交通
情况，务必随时准备迅速采取措施。不遵守这些说明可能
导致财产损坏、严重的人员伤害或死亡。
警告： 辅助转向 以受控道路（城市快速路以及高速公
路）为主要使用场景而设计，并要求道路必须设有中央隔
离带和清晰的车道标线，不得出现交叉口，车道宽度不小
于 2 米。倘若道路存在急弯或车道标线缺失、褪色或模糊
不清，则不得使用辅助转向。虽然辅助转向也可以在乡村
道路（带中心线或草地路肩）、住宅区街道、城市道路等
非受控道路启用，但您可能对其使用效果感到不满意或不
确定。使用此功能时，必须注意路况，专心驾驶车辆，双
手放在方向盘上，以便随时干预。请勿在施工区域或可能
有自行车或行人的路段使用辅助转向。

车、行人以及动物、锥桶、纸箱、水马、轮胎和三角警示
牌等）。

法正常工作：
• 辅助转向 无法准确判断车道线。例如，车道线过度磨

• 接近收费站。
• 在有急转弯或崎岖不平的道路上行驶。
• 强光（如阳光直射）妨碍摄像头视野。
• 传感器（如果配备）受其他可产生超声波的电气设备

• 开启转向信号灯后，探测到盲区有车辆出现。
